# Northeast India Plantation Crop Yield Prediction

Agro-climatic machine learning and deep learning pipeline for predicting Tea and Rubber yields across Northeast India.

## Methodology & Stack
- **Data Processing:** Pandas, NumPy, Scikit-learn
- **Modeling & Tuning:** XGBoost, PyTorch feedforward neural network, Optuna hyperparameter optimization, and ensemble blending
- **Interpretability & Evaluation:** SHAP feature importance, correlation heatmaps, and actual vs. predicted yield diagnostics

## Repository Structure
- `ne_crop_yield_prediction.ipynb` — End-to-end training, tuning, and evaluation notebook
- `ne_crop_data.csv` — Regional agro-climatic and crop yield dataset
